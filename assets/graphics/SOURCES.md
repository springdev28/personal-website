# Flat vector graphics

The desk props, folder symbols, log-folder symbols, and non-WebGL fallback use SVGs from [Iconoir](https://iconoir.com/), an open-source icon library by Luca Burgio and contributors.

The SVGs were downloaded from the official [`iconoir-icons/iconoir`](https://github.com/iconoir-icons/iconoir) repository and are used under its MIT license. The repository license is stored beside them as `LICENSE`.

Included source files:

- `camera.svg`
- `coffee-cup.svg`
- `color-picker.svg`
- `cube.svg`
- `design-pencil.svg`
- `laptop.svg`
- `media-image.svg`
- `open-book.svg`
- `palette.svg`
- `ruler-combine.svg`
- `scissor.svg`

The interface applies these SVGs as CSS masks so the original linework can take on the site's flat palette without editing the source paths.
